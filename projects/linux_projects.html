Ubuntu DHCP and DNS Configuration

Configured core network services on Ubuntu to provide automatic addressing and reliable hostname resolution in a lab environment.

Overview

This project focused on building a functional Linux networking setup for a small internal network. The goal was to configure DHCP for automatic client addressing and DNS for hostname resolution so devices could communicate using names instead of raw IPs.

Project goals

  • Provide automatic IP assignment to clients through DHCP.
  • Configure DNS to resolve hostnames within the environment.
  • Verify connectivity and name resolution from client devices.
  • Document the setup in a repeatable, lab-friendly format.

DHCP configuration

Set up the DHCP service on Ubuntu to assign IP addresses, default gateways, and DNS settings to clients automatically. The configuration included address ranges, lease timing, and network-specific options so devices joining the network could receive working configuration without manual setup.

DNS configuration

Configured name resolution so hostnames in the environment could be translated into the correct addresses. This created a cleaner and more reliable internal networking setup, making it easier to manage services and test connectivity between machines.

Verification

Validated the environment by confirming that clients received DHCP leases and were able to resolve hostnames successfully. Testing included checking client addressing, connectivity, and DNS response behavior to ensure the services were functioning as expected.
