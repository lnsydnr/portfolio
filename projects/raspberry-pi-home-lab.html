SELF-STUDY

Raspberry Pi Home Lab

A compact home environment for network services, device monitoring, and secure file access.

Overview

Deployed several practical services on Raspberry Pi hardware to make the home network more observable and manageable. Each service provided a hands-on opportunity to work with access control, reliability, and network behavior.

Focus areas

  • Adguard for network-wide DNS filtering
  • Home Assistant for monitoring and automation
  • Access-controlled SMB file storage
  • Secure service configuration on a personal network

Implementation

Home Assistant Setup

Configured a Raspberry Pi 5 with a custom-built case and a 128GB microSD card to host the various services. Used a custom image for Home Assistant OS using the Raspberry Pi Imager. Installed and configured each service with appropriate security measures and access controls. Configured Adgaurd for DNS-filtering and Cloudflare Tunnel for secure remote access.


Adguard DNS Filtering

Installed Adguard Home on the Raspberry Pi to provide network-wide DNS filtering. Configured it to block ads, trackers, and malicious domains, improving network performance and security for all connected devices.


Cloudflare Tunnel

Configured a Cloudflare Tunnel to securely expose the Home Assistant instance to the internet without opening ports on the home router. This allows for secure remote access to the home lab services while minimizing exposure to potential threats. Set up Zero Trust access controls by configuring authentication and authorization policies.

Outcome

Created a working, self-managed lab that supports daily use while providing a safe environment for testing infrastructure and security changes.
