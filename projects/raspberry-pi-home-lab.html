SELF-STUDY

Raspberry Pi Home Lab

A compact home environment for network services, device monitoring, and secure file access.

Overview

Deployed several practical services on Raspberry Pi hardware to make the home network more observable and manageable. Each service provided a hands-on opportunity to work with access control, reliability, and network behavior.

Focus areas

  • Pi-hole for network-wide DNS filtering
  • Home Assistant for monitoring and automation
  • Access-controlled SMB file storage
  • Secure service configuration on a personal network

Outcome

Created a working, self-managed lab that supports daily use while providing a safe environment for testing infrastructure and security changes.

PROJECT SIGNALS
