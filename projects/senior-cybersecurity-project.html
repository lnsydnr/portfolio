Senior Cybersecurity Project

Designed, secured, tested, and documented a small company LAN as a capstone security project.

Overview

Built a secure network with routers, switches, servers, and an Apache web server, then assessed the environment from an attacker’s perspective. The project connected infrastructure configuration with practical vulnerability management.

Focus areas

  • Secure LAN and server configuration
  • Penetration testing and vulnerability discovery
  • Remediation planning and validation
  • Technical documentation and configuration write-ups

Outcome

Produced a complete technical record of the network configuration, vulnerabilities found, remediation steps, and post-change validation.

PROJECT SIGNALS
