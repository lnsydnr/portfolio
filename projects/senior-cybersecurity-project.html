CAPSTONE · SUMMER 2022

Senior Cybersecurity Project

Designed and assessed a segmented company LAN with an internal Apache server in a virtualized Cisco lab.

Project overview

Built a small-company network in GNS3 using three Cisco routers, a managed switch, user workstations, Kali Linux, and an Ubuntu server running Apache. The lab brought together network design, device hardening, penetration testing, and connectivity validation.

Network design

  • Connected three routers with OSPF so office and server subnets could communicate.
  • Segmented office workstations and the Kali test machine on VLAN 10, with switch port security enabled.
  • Hosted the Apache web server on a separate Ubuntu subnet behind the third router.
  • Configured NAT and an extended access control list on the edge router for upstream connectivity.

Hardening and assessment

Router controls included long-password requirements, scrypt-based secret storage, failed-login lockout and logging, and idle session timeouts. From the Kali system, Nmap identified FTP, SSH, and HTTP exposed on the lab server. Metasploit’s credential-sniffing module and John the Ripper were then used in the isolated lab to demonstrate how exposed FTP credentials and accessible password hashes could lead to account compromise.

The assessment highlighted the risk of plaintext file transfer and weak credential handling. These findings informed hardening priorities; the project records configuration and assessment results rather than claiming that every finding was remediated.

Validation and outcome

Connectivity checks were recorded between the workstations, routers, server, and upstream network. Router tables and access-list match counters were also inspected to verify routing and permitted traffic. The project produced a documented network design, device configurations, test results, and a practical demonstration of how layered controls and secure service choices reduce exposure.
